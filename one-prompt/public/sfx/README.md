Drop optional sound effects here (mp3, wav, m4a, aac or ogg):

| file                  | used for                                  |
|-----------------------|-------------------------------------------|
| `alarm.*`             | morning alarm clock (scene 4)             |
| `keyboard.*`          | typing on the laptop (scenes 4, 5, 6)     |
| `rain.*`              | rainy night, looped (scene 5)             |
| `paper-crumple.*`     | crumpling / un-crumpling the chart (2, 3) |
| `ding.*`              | green check marks + chat reply (4, 5)     |

Missing files are skipped and the film renders silently. Re-run
`npm run preview` / `npm run render` after adding files (they rescan /public).
