# Sound effects

Every audio file in this folder is picked up automatically under its base name
(`rain.mp3` → `<Sound name="rain" />`). Missing files are skipped, so the film
still renders without them. All files were generated with ElevenLabs Sound
Effects v2 and level-normalized: one-shots peak at −1 dBFS, ambiences sit around
−30 dB average.

| file | used for |
|------|----------|
| `cafe` | café murmur, cups, espresso machine (loop) – scenes 1, 3, 6 |
| `room-evening` | apartment room tone, distant traffic (loop) |
| `room-night` | quiet night, fridge hum (loop) |
| `rain` | rain on the window (loop) – scene 5 |
| `morning-birds` | birdsong outside (loop) – scene 4 |
| `office` | office air conditioning + murmur (loop) – scene 4 |
| `thunder` | distant thunder – scene 5 |
| `footsteps` | MAX walks to the wall, the BOSS walks in |
| `pin` | chart pinned to the wall |
| `laptop-turn` | MAX turns the laptop towards LENA |
| `keyboard` | typing (prompts, notes, FRIEND) |
| `click` | trackpad clicks |
| `send` | chat message sent |
| `ding` | AI reply arrives / soft success chime |
| `sigh` | MAX sighs |
| `marker-x` | red X drawn on the chart (one per X) |
| `marker-check` | green check drawn on the chart |
| `marker-write` | "1 PROMPT" written with a marker |
| `paper-rip` | chart pulled off the wall |
| `paper-crumple` | chart crumpled |
| `bin` | paper ball lands in the bin |
| `paper-unfold` | chart pulled out of the bin and smoothed |
| `paper-flip` | chart flipped to the back |
| `fridge` | fridge door opens |
| `phone-slide` | phone slid across the café table |
| `cup` | coffee cup set on a saucer |
| `sofa` | cushion creak (sitting up) |
| `alarm` | morning alarm clock |
| `pop` | speech/thought bubble appears (automatic) |
| `title-swell` | soft swell under title cards (automatic) |
